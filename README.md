# Custom Cake Builder

## Project Overview

Custom Cake Builder is an interactive frontend project built with Next.js, React, and Tailwind CSS.

Users can:

- Select cake frosting
- Add or remove a candle
- Enter a custom cake message
- View changes in real time
- Reset the cake

## Technologies Used

- Next.js
- React
- JavaScript
- Tailwind CSS
- Next.js Image
- React useState
